# Implementation provenance

The requirements originate in the owner's workflow specification, initially named MatiQ Guides and renamed MatiQ Copycat. Public documentation and the limited read-only source inspection are identified below. No competitor code, algorithms, tests, comments, component structure, screenshots or assets were copied, translated or adapted into this implementation. Mimik is not a dependency.

The foundation was generated by the qualified MatiQ Solutions SDK 0.1.3 release CLI (tag commit 9c799aeecd1bf4ef20c7e882963d7154fed0d84b). Runtime, shell behavior, brand resources and no-sale source-available license remain first-party SDK supplied. Guide persistence and editing are independently implemented in this repository.

Chrome and Mozilla native messaging documentation were read on November 7, 2026 for transport framing, host allowlists and browser registration. Dependency notices remain with the packages actually used and in the packaged NOTICE/LICENSE files.

Microsoft Edge native messaging, Mozilla's current Firefox data-transmission consent taxonomy and the Chrome DevTools Protocol Extensions domain were also consulted for browser integration and controlled test invocation. Browser content capture, the native stdio helper, private authenticated socket, acknowledgement protocol and recovery logic are independently implemented. The Linux test transport launcher is a controlled fixture, not a second shipped bridge or tool implementation.

Apple's ScreenCaptureKit SCScreenshotManager, NSEvent global mouse monitoring and AXUIElement documentation, together with the installed Apple SDK declarations, were consulted for the independently written selected-window helper. No general computer-control or competitor capture implementation was reused. The AppKit fixture is original controlled test code.

- https://developer.apple.com/documentation/applicationservices/axuielement

Firefox permission behavior was checked against Mozilla's [captureVisibleTab](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/tabs/captureVisibleTab), [optional host permissions](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/optional_host_permissions), and [geckodriver flags](https://firefox-source-docs.mozilla.org/testing/geckodriver/Flags.html) documentation. The owned Firefox qualification fixture invokes the installed browser's WebDriver event API for trusted UI input. No Mozilla implementation source is copied, adapted, vendored or shipped by Guides; geckodriver is a test-only external tool. Permission UI, capture scope guards and failure handling are independently implemented.

Standalone updating reuses the installed suite's MIT-licensed electron-updater **6.8.9**, pinned with resolved dependencies. Its published package/type declarations and Electron/Squirrel primary documentation were inspected. The local cache, no-rollout-ID adapter, explicit UI and SDK-safe shutdown integration are independently implemented. Shipped third-party notices and upstream package author/license metadata are preserved; Guides does not claim ownership of dependency code. The AppKit normal-quit fixture uses documented NSRunningApplication behavior and verifies actual termination. No competitor implementation was used for updating or protocol-quarantine tests.

The official [Chrome DevTools Protocol ServiceWorker schema](https://github.com/ChromeDevTools/devtools-protocol/blob/master/json/browser_protocol.json) was consulted for test-only worker-state events and exact-version stop commands. Worker recovery, connection validation and the owned browser regression are independently implemented. The fixture stops only the identified extension worker in its own temporary browser profile.

The installed Apple SDK NSRunningApplication declarations and [AppKit activation documentation](https://developer.apple.com/documentation/appkit/nsrunningapplication/activate(options:)) were consulted for the test-only owned-browser focus helper. The independently written helper checks process/bundle identity, requests normal activation and waits for actual macOS active state. It neither changes production capture guards nor inspects another application's content.

Keyboard button activation was reproduced independently in the owned browser fixture. Mozilla's [click event](https://developer.mozilla.org/en-US/docs/Web/API/Element/click_event) and [UIEvent.detail](https://developer.mozilla.org/en-US/docs/Web/API/UIEvent/detail) references were consulted for event semantics. The listener change and trusted-input regression are original MatiQ code; no browser implementation code is copied or shipped.

Document-transition readiness, reply deadlines and cancellation checks were implemented from failures in MatiQ's own streamed-page browser fixture. The fixture uses real browser navigation and screenshot APIs, with controlled HTTP response timing; it does not copy or adapt an external capture implementation.

Editor history and the capture/editor redesign are original MatiQ work using SDK-supplied shell styles, colors and fonts.
