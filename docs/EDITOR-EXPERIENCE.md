# Document editor

The guide itself is the editing surface. Each numbered step keeps its instruction and annotated screenshot together; choosing its text opens inline editing in that card. A compact outline provides navigation. Insert controls add a manual step at the chosen position, preserving existing identities.

Checkboxes select multiple steps. A persistent MatiQ selection bar moves them earlier/later, duplicates the ordered selection, or deletes it as one undoable operation. Screenshot editing remains attached to its step. Preview images flatten current annotations and redactions; original screenshots remain in editable projects as documented in the project format.

The existing project model, SDK shell, local persistence and export are shared by standalone and suite. No cloud Pages/teams, collaboration, translation or automatic animated merging is introduced. The public Scribe tutorial was an observable functional reference only; Copycat has its own layout, wording, colors, controls and implementation. See PROVENANCE.md.
